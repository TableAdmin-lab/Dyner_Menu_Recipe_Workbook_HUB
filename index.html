Guides

Step-by-step instructions for each part.

Using the Workbook Updater
  1. Type the site name. It goes in front of the file name in brackets, e.g. (DYNER Claremont) DYNER_Menu_Recipe_Workbook_UPDATED.xlsx.
  2. Add the recipes file. This one is required.
  3. Add the ingredients and manufacturing recipes files if you have them.
  4. Click Update workbook and download.
  5. If a Check in the workbook box appears, fix those items in the workbook.

Completing the workbook
  • Work in the rows below the second header row on each tab. The rows above it are examples; leave them as they are.
  • Pick ingredients from the drop-downs. A cell that turns red doesn’t match anything on the Ingredients tab.
  • Manufactured ingredients show with (MAN) after the name in the drop-downs. That’s expected.
  • To make an ingredient a manufactured item, set is_manufactured to Yes on the Ingredient Import tab.
  • Units, costs and the output ingredient are filled by formulas. Don’t type over them.
  • If a unit shows Not found, fix the ingredient’s spelling or add it to the ingredients list.
Using the Workbook Exporter
  1. Type the site name. It goes in front of each exported file name.
  2. Upload the completed workbook.
  3. Leave Remove “ (MAN)” from ingredient names ticked so names match the ingredients import.
  4. Download each file, or use Download all three as a zip.
  5. If a Check before importing box appears, review it first.

Questions and fixes

The things that come up most.

The Update button is greyed out

The recipes file is required. Add it and the button turns on.

A Recipe Name cell is red

That output ingredient isn’t on the ingredients list, or isn’t marked as manufactured. Add it on the Ingredient Import tab with is_manufactured set to Yes.

Units show “Not found”

The ingredient name doesn’t match any ingredient. Pick it from the drop-down or add the missing ingredient.

Will running the Updater twice duplicate data?

No. Every run starts from a fresh copy of the template.

The workbook looks blank when it opens

Excel recalculates on open. If values stay blank, set Formulas › Calculation Options to Automatic.

The tools won’t load

Both tools run in your browser and need internet to load their Excel libraries. Files are never uploaded to a server.
